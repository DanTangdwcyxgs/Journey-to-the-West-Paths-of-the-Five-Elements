# 《西游：五行之路》

> 五个角色，五条人生起点，一条固定西游历史。

**《西游：五行之路》**是一款以经典《西游记》为叙事核心的像素 HD-2D 回合制 JRPG。

英文工作名：**Journey to the West: Five Elements Road**

项目希望做的不是“西游角色套一个普通 RPG”，而是：

> **让玩家真正陪唐僧、悟空、八戒、悟净和白龙马走完一遍西游。**

---

## 30 秒看懂这个项目

玩家可以从五个人中的任意一个开始：

**孙悟空 / 唐三藏 / 猪八戒 / 沙悟净 / 白龙马**

每个人都有自己的前史和人物故事。

但玩家选择的是**第一视角**，不是改变西游历史。

因此游戏的核心结构是：

```text
选择一个角色
      ↓
体验他的个人历史
      ↓
抵达经典西游节点
      ↓
进入共同世界时间线
      ↓
逐步招募其他角色
      ↓
开放个人 Memory / 人物故事
      ↓
五人组成完整队伍
      ↓
一起继续西行
      ↓
走完完整西游
```

这让游戏拥有“五个入口”的重玩价值，同时保持**一条世界历史、一套真正的西游主线**。

---

# 游戏怎么玩？

核心循环不是简单的“跑地图 → 打怪 → 下一关”。

游戏会反复经历：

```text
剧情
 ↓
探索
 ↓
NPC / 传闻 / 地标
 ↓
选择与事件
 ↓
普通遭遇
 ↓
地下城 / 区域探索
 ↓
Boss / 经典妖怪
 ↓
奖励与世界变化
 ↓
营地 / 队伍 / 关系
 ↓
装备 / 技能 / Memory
 ↓
前往下一个西游目的地
```

玩家既要考虑战斗，也要理解人物、经营队伍和推进旅途。

# 五个角色，五种玩法

## 孙悟空

**主题：自由 vs 束缚**

高攻击、高机动、破盾、爆发、变招。

他的故事从石猴、花果山、寻仙、龙宫、地府一路走到大闹天宫和五行山。

他的玩法目标是让玩家真正感觉到：

> “我可以打破一切规则。”

然后逐渐理解为什么“拥有力量”并不等于“拥有自由”。

## 唐三藏

**主题：信仰 vs 现实**

治疗、保护、净化、判断、谈判和风险管理。

唐僧不是一个等悟空来救的辅助，而是一个真正拥有自己价值观和主线的主人公。

## 猪八戒

**主题：欲望 vs 责任**

高生命、高防御、怒气、蓄力和打断。

先让玩家认识天蓬元帅，再看到被贬后的猪刚鬣，最后理解为什么八戒会成为队伍中不可缺少的人。

## 沙悟净

**主题：罪责 vs 救赎**

防御、控制、持续作战和稳定性。

核心体验不是“一个安静的坦克”，而是一个已经习惯被放逐的人重新接受责任。

## 白龙马

**主题：身份 vs 使命**

速度、元素、形态变化和战术切换。

前期玩家会先把他认识为“白马”，之后逐渐发现他的龙族身份和真正战斗能力。

---

# 西游世界的核心规则

### 玩家顺序自由

五个角色都可以作为新游戏起点。

### 世界顺序固定

西游历史只有一条，不因为玩家选择八戒开局就让世界直接跳到高老庄，也不会产生五个平行宇宙。

### 招募是故事事件

角色在经典西游节点真正进入取经队伍，而不是因为等级或抽卡加入。

大方向：

```text
悟空被镇压
↓
唐僧开始取经
↓
五行山释放悟空
↓
白龙马加入
↓
高老庄收八戒
↓
流沙河收悟净
↓
五人完整西行
```

### 个人故事不会消失

角色加入队伍后，他过去的故事会继续通过 Memory / Character Perspective 形式开放。

Memory 不会篡改当前世界时间线。

# 战斗系统

战斗采用现代 HD-2D JRPG 的设计语言，同时让西游人物自己的性格成为玩法的一部分。

## Weakness

敌人拥有不同弱点。

玩家需要选择正确的角色和技能。

## Shield / Break

针对弱点攻击可以削减 Shield。

Shield 归零以后进入 Break：

- 敌人暂时无法行动；
- 受到更高伤害；
- 玩家获得爆发窗口。

## BP / Boost

每回合积累 BP。

玩家可以保存 BP，把它投入关键技能，在最需要的时候爆发。

## 3 前排 / 2 后排

队形真正参与战斗规则。

前排更容易承受压力；后排受到一定保护，并可以形成不同战术。

## 角色专属机制

五个人不是换头像，而是五种不同战斗思路。

# 旅途与世界探索

目前项目已经建立数据驱动的世界地图、旅行、传闻和悬赏基础。

当前探索骨干：

```text
五行山
 ↓
鹰愁涧
 ↓
黑风山北道
 ↓
高老庄
 ↓
流沙河
 ↓
龙骨秘境
```

玩家可以：

- 探索地图；
- 听到地方传闻；
- 发现悬赏；
- 进入普通遭遇；
- 进入 Boss 战；
- 回到世界继续旅行。

同时存在营地、装备、消耗品和队伍准备方向。

# 81 难怎么做？

不会做成 81 个大型副本。

长期规划是：

- 约 12–15 个大型主线试炼；
- 约 20–25 个中型故事；
- 其余由支线、精英、特殊事件、环境挑战和小型剧情组成。

这样可以保留西游“一路都有劫难”的感觉，同时避免重复刷关。

# 项目为什么值得长期投入

## 1. 文化认知基础强

西游拥有非常成熟的人物、地点、冲突和故事记忆点。

## 2. 五主角结构天然支持长期内容

同一条世界线可以持续增加：

- 个人 Memory
- 营地事件
- 人物关系
- 组合技能
- 新章节
- 支线故事

## 3. 可以从小型 Vertical Slice 逐步放大

不是一开始就承担完整 81 难的全部制作成本，而是先做一条完整产品样板，再规模化生产。

## 4. 系统与内容逐渐数据驱动

未来新增章节、敌人、技能、事件、奖励和世界节点，应尽可能通过数据和通用 Runtime 扩展，而不是复制程序。
