# 《西游：五行之路》——投资人与合作方快速了解

## 项目是什么

《西游：五行之路》是一款以经典《西游记》为叙事核心的像素 HD-2D 回合制 JRPG。

它的核心并不是重新发明西游世界，而是把玩家最熟悉的西游人物、地点和故事转化成一款真正可以持续游玩的角色扮演游戏。

## 为什么值得做

西游拥有非常强的文化认知基础，但“完整地以五个主要人物共同成长、共同取经”为核心的现代 JRPG 体验仍然拥有很大的表达空间。

本项目希望把三种优势叠加：

**西游的文化认知 + 现代 JRPG 的长期玩法 + 像素 HD-2D 的低成本高表现力方向。**

## 最核心的产品概念

### 五个起点

玩家可以从：

孙悟空 / 唐三藏 / 猪八戒 / 沙悟净 / 白龙马

中的任意一个开始。

### 一条历史

五个起点不是五个平行宇宙。

玩家只是先看到不同人物的人生，之后都会汇入同一个西游历史。

因此产品结构是：

```text
5 个个人入口
      ↓
5 条人物成长路线
      ↓
固定西游时间线
      ↓
逐步招募
      ↓
5 人队伍
      ↓
共同西行
```

这同时提供了重玩价值和稳定的世界观。

## 游戏怎么留住玩家

玩家的驱动力不是单一刷数值，而是四条线同时推进：

### 1. 故事驱动

想知道下一个西游名场面会怎样被“玩出来”。

### 2. 人物驱动

不断了解悟空、唐僧、八戒、悟净、龙马为什么变成今天的样子。

### 3. 战斗驱动

Weakness → Shield → Break → BP / Boost → 队形 → 角色专属机制。

### 4. 旅途驱动

世界地图、传闻、支线、营地、装备、Memory 和各种旅途事件共同形成长期探索动力。

## 战斗不是独立小游戏

西游人物的性格会进入战斗系统。

悟空强调爆发与高主动性；唐僧强调保护、净化和判断；八戒强调耐久与怒气；悟净强调持续与控制；龙马强调形态与适应。

因此玩家不仅通过对白理解角色，也通过操作理解角色。

## 内容规模

“81 难”被设计为长期内容框架，而不是 81 个完全一样的大副本。

计划由：

- 大型主线试炼
- 中型故事
- 支线
- 精英战
- 特殊事件
- 环境挑战

共同组成。

这让内容可以持续扩展，同时避免重复。

## 开发策略

项目采用分阶段路线：

```text
基础架构
↓
完整 Vertical Slice
↓
五条 Origin Route
↓
角色 Memory / Camp / Relationship
↓
Shared Journey
↓
大规模西游章节生产
↓
美术 / 音频 / 演出升级
↓
发行版本
```

不是先花巨大成本把整部西游全部制作完成，而是先验证一条完整的可玩样板，再进行规模化生产。

## 当前已经建立的技术资产

项目已经具备：

- 五角色叙事架构
- 固定世界时间线
- Origin / Shared 双层叙事
- 招募与 Memory 基础
- 3 前 / 2 后队形
- Weakness / Shield / Break
- BP / Boost
- Speed / Status
- 数据驱动技能与敌人
- 角色专属机制基础
- 龙马变身
- Inventory / Equipment
- World Map / Rumor / Bounty
- 黄风岭 / 黄风洞探索样板
- 三场共享招募战
- 原子化战斗结算
- ChapterDefinition / ChapterRuntime
- 面向批量内容生产的 Pipeline
- 面向未来 AI / Agent 的接管与开发日志体系

## 当前最重要的产品验证

接下来并不是继续无限扩展底层代码，而是完成第一条完整 Vertical Slice：

```text
五行山
→ 鹰愁涧
→ 白龙马加入
→ 黑风山
→ 黄风岭
→ 黄风洞
→ 黄风妖王
→ 善后
```

这一段要同时验证：

故事、地图、探索、战斗、Boss、招募、队伍、装备、营地、保存/读取和世界状态。

## 长期愿景

最终做成一款让玩家在结束游戏时产生“我真的和唐僧师徒一起走完了这一路”的西游 JRPG。

项目的终局不是一个孤立的孙悟空故事，而是：

**五个人的五段人生，最终变成一条共同的西游。**
