# 五个起始角色：章节级制作圣经

> 本文把“五人都可以作为新游戏起点”落实到章节粒度。
>
> 核心原则：**选择角色影响玩家进入故事的视角，不改变西游世界的固定历史顺序。**
>
> 另一个不可违反的规则：**遇见/招募一个角色后，该角色个人主线立即解锁，不需要等待五人聚齐。**

## 1. 章节生产模板

每个正式章节至少回答八件事：

1. 这一章为什么存在：人物弧、电视剧节奏、世界信息。
2. 玩家在哪里：地图结构、可探索区域、关键地标。
3. 玩家做什么：探索、调查、对话、解谜、战斗。
4. 玩家打什么：普通敌人、精英、Boss、弱点类型。
5. 角色获得什么：技能、被动、装备、资源、玩法变化。
6. 世界发生什么：唯一的 global timeline milestone。
7. 章节结束在哪里：下一章入口与共享时间线交接点。
8. 从其他起始角色进入时如何处理：哪些内容成为历史回忆，哪些属于当前世界。

章节不是纯小说。每章必须产生至少一种**可玩的新行为**或**新的叙事理解**。

# 2. 孙悟空开局

## 路线定位

这是“五人起始路线”中最强的动作/战斗成长线，也是玩家第一次认识三界、天庭与世界规则的入口。

核心情绪：**自由 → 反抗 → 失去自由 → 等待第二次人生。**

### WUK-01 石猴出世

**剧情**：花果山石猴出生、群猴生活、发现水帘洞。

**地图**：花果山外圈 → 猴群区域 → 水帘洞内部。

**玩法**：移动教学、攀爬、基础攻击、环境互动、第一次弱点战。

**战斗**：山兽、山精、训练型猴群冲突。

**成长**：只开放基础棍击与轻重攻击；重点是移动与观察。

**收束**：悟空发现“山中自由并不能回答生死”。

**Milestone**：`WUKONG_BORN`。

### WUK-02 水帘洞主

**剧情**：悟空成为猴王，建立自己的秩序。

**地图**：水帘洞社群、瀑布、后山。

**玩法**：第一次营地/资源管理；收集食物、药材、简易装备。

**Boss**：区域霸主级山兽，不是终极敌人，用于展示悟空成长空间。

**成长**：解锁基础棍法分支与第一次主动技能。

**主题**：自由不仅是“不听别人”，也意味着承担猴群后果。

### WUK-03 寻仙问道

**剧情**：悟空离开花果山寻找长生法。

**地图**：海岸、船路、陌生城镇、山门外围。

**玩法**：首次长距离地图、NPC rumor 系统、旅途事件。

**战斗**：海怪、山贼、低阶妖物。

**奖励**：开启“悟性”类永久成长。

### WUK-04 菩提门下

**剧情**：拜入菩提祖师门下。

**地图**：方寸山、斜月三星洞、修行场。

**玩法**：非传统战斗训练章节；通过试炼学习系统。

**系统解锁**：闪避、蓄力、变招、法术基础。

**核心设计**：玩家感受到“悟空第一次真正变强”，但不能立刻把所有能力一次性给满。

### WUK-05 大圣初醒

**剧情**：修成神通，回到花果山。

**地图**：花果山新区域；此前地图可回访。

**玩法**：能力检验型开放地图。

**解锁**：七十二变基础、筋斗云。

**叙事**：新力量让悟空第一次开始与“凡间规则”脱节。

### WUK-06 龙宫取宝

**剧情**：悟空进入东海龙宫取兵器。

**地图**：海面 → 水晶宫 → 宝库。

**玩法**：水下探索、机关、装备选择。

**Boss**：龙宫守卫/试炼战。

**关键奖励**：如意金箍棒。

**Milestone**：`JINGUBANG_OBTAINED`。

### WUK-07 地府改命

**剧情**：悟空死后闯入地府，修改生死簿。

**地图**：黄泉渡口 → 地府街区 → 阎罗殿。

**玩法**：潜入/调查与强制战斗混合；首次出现“神权系统”概念。

**核心选择**：不是分支结局，而是让玩家理解悟空拒绝接受既定命运。

**Milestone**：`LIFE_DEATH_REGISTER_ERASED`。

### WUK-08 弼马温

**剧情**：受招安入天庭，成为弼马温。

**地图**：天门、御马监。

**玩法**：第一次“非战斗身份”章节；任务、NPC关系、工作流程。

**叙事目的**：天庭不是单纯副本，而是一个有官僚秩序的世界。

### WUK-09 齐天大圣

**剧情**：悟空看清天庭态度后再次反抗，自号齐天大圣。

**地图**：花果山与天庭交替。

**玩法**：第一次大规模防守战/据点战。

**成长**：解锁更高等级棍法与群体技。

**Milestone**：`WUKONG_REBELLED`。

### WUK-10 偷食蟠桃

**剧情**：蟠桃会与老君丹药形成连续事件。

**地图**：瑶池、蟠桃园、兜率宫。

**玩法**：潜入、追逐、资源风险。

**状态变化**：悟空进入“极高战力但世界敌意同步提高”的阶段。

### WUK-11 天兵天将

**剧情**：天庭多轮围剿。

**玩法**：多波战斗、精英战、首领战连续结构。

**系统**：完整 Break/BP 思路第一次高强度使用。

**目标**：不是简单刷怪，而是让玩家觉得一支天兵军队正在逐步压缩悟空的活动空间。

### WUK-12 二郎神

**剧情**：二郎神受命对阵悟空。

**地图**：花果山 → 天空战场 → 变化战场。

**玩法**：Boss 具有形态变化与弱点变化。

**核心战**：二郎神必须成为悟空前半生最重要的一场单挑。

### WUK-13 炼丹炉

**剧情**：悟空被镇入太上老君炼丹炉，反而炼成火眼金睛。

**地图**：丹炉内部。

**玩法**：特殊生存/环境伤害章节；不采用普通迷宫逻辑。

**解锁**：火眼金睛，用于识别伪装、隐藏敌人与部分剧情真相。

### WUK-14 大闹天宫

**剧情**：最终反抗与失败。

**玩法**：大型连续战斗 + 神话场景切换。

**设计重点**：这是悟空路线的“不可胜利战”；玩家能赢战斗，但不能赢历史。

### WUK-15 五行山

**剧情**：如来降服悟空，镇压五行山。

**玩法**：战斗弱化，强调最后一段“无法逃离”的心理体验。

**Milestone**：`WUKONG_SEALED`。

**路线结尾**：悟空不是死亡，而是“成为历史中的一个等待者”。

**与唐僧线交汇**：唐僧到达五行山时，同一世界事件以另一镜头实现。

# 3. 唐僧开局

## 路线定位

唐僧不是战斗教学路线，而是**判断、准备、信仰与人与人关系**路线。

### TANG-01 金蝉转世

身份伏笔、前世因缘。作为短篇序章，不一次解释所有设定。

### TANG-02 寺中少年

江流儿成长、佛法与慈悲建立。玩法以寺院探索、NPC关系和轻量事件为主。

### TANG-03 出家

受戒与第一次离开世俗生活。解锁经文/符箓系统。

### TANG-04 取经之愿

接受使命。第一次把“西天取经”从个人信念变成世界任务。

### TANG-05 观音点化

观音建立使命框架；唐僧第一次知道自己必须经过真正的危险道路。

### TANG-06 西行初程

单人/护卫状态。重点玩法：识别伪装、谈判、避战、净化。

### TANG-07 五行山

遇见悟空。镜头从“唐僧眼中的陌生囚徒”建立关系。

### TANG-08 紧箍

悟空正式加入。解锁双人战斗、紧箍咒与师徒关系值。

### TANG-09 黑风山前

第一次共同旅行。章节结束后，队伍进入固定的早期西行主线；同时 `WUKONG_ROUTE` 已立即可在个人故事界面使用。

# 4. 猪八戒开局

## 路线定位

八戒路线必须让玩家先喜欢/理解“天蓬”，再看到“猪妖”，最后理解“八戒”。

核心情绪：**天上有身份 → 被放逐 → 想过普通生活 → 被过去追上 → 主动承担责任。**

### BAJIE-01 天蓬元帅

**地图**：天河水府、天庭军营。

**玩法**：重武器战斗、军阵训练、天兵协同。

**角色手感**：高生命、高防御、强力蓄力。

### BAJIE-02 天河旧梦

**地图**：天河、天庭宴席、军府。

**玩法**：关系与选择型事件；让玩家看到天蓬对享乐、酒宴、凡间情感的向往。

### BAJIE-03 被贬凡间

**剧情**：犯错、受罚、投错胎。

**玩法**：能力骤降，形成“强者跌落”的反差。

**系统**：食物资源、饱腹、受伤强化雏形。

### BAJIE-04 猪刚鬣

**地图**：荒野、山林、村落外围。

**玩法**：生存、狩猎、拾荒；首次使用八戒的“懒而高效”玩法。

### BAJIE-05 云栈洞

**地图**：洞府及周边山地。

**玩法**：资源储存、洞府经营、招募小妖/处理小型威胁。

**叙事**：八戒开始欺骗自己“这样也可以一直活下去”。

### BAJIE-06 高老庄

**地图**：高老庄街区、农田、宅院、后山。

**玩法**：调查村民口供、夜间潜入、关系事件。

**NPC**：高家众人、高翠兰、村民、商户。

**叙事核心**：八戒并不是纯粹“抢亲”，而是欲望、身份羞耻和对普通生活的执念撞在一起。

### BAJIE-07 猪妖与和尚

**剧情**：悟空调查高老庄；八戒与悟空首次交锋。

**玩法**：追逐、伪装、连续小战。

**角色战**：八戒第一次让玩家真正面对“另一个完整可玩人物”。

### BAJIE-08 三打高老庄

**结构**：调查 → 误会 → 第一次 Boss → 逃脱 → 第二次交锋 → 唐僧介入。

**Boss**：悟空 vs 八戒不是单纯击杀，而是“压制并逼出身份”。

### BAJIE-09 放下

**剧情**：八戒最终接受取经道路。

**Milestone**：`ZHU_BAJIE_RECRUITED`。

**路线结束方式**：如果玩家从八戒开局，此处不要自动把世界倒回花果山；直接把玩家接入当前共同旅程的对应 checkpoint。

**个人线解锁**：八戒加入共同旅程后，其余八戒历史章节立即成为可进入内容，不需要 PARTY_FULL。

# 5. 沙悟净开局

## 路线定位

沙僧是五人中最“稳定”的路线：慢、重、冷静，但具有非常强的赎罪感。

### WUJING-01 卷帘大将

**地图**：天庭仪仗区域、凌霄体系外围。

**玩法**：防御、护卫、队列战斗。

### WUJING-02 失手

**剧情**：因失手打碎琉璃盏而获罪。

**玩法**：不是大型战斗章节，而是身份瓦解。

### WUJING-03 流沙河

**地图**：流沙河上下游、河床洞穴。

**玩法**：水域探索、潜水、拖拽、耐力。

### WUJING-04 无尽

**剧情**：长年受罚、吞噬过往取经人。

**玩法**：重复环境中加入变化，表现“无尽囚困”；可通过环境叙事减少对白。

### WUJING-05 河中来客

**剧情**：新的取经人接近。

**玩法**：伏击、防守、河道控制。

### WUJING-06 观音渡厄

**剧情**：观音引导沙悟净走出循环。

**玩法**：第一次允许“保护目标而非击杀目标”成为战斗主目标。

### WUJING-07 流沙河之战

**剧情**：悟空/八戒与沙悟净交锋，最终识破身份。

**玩法**：高防御 Boss、护盾、控制、反击。

### WUJING-08 皈依

**剧情**：正式加入。

**Milestone**：`SHA_WUJING_RECRUITED`。

**路线结束**：直接接入当前世界 checkpoint；沙僧个人历史立即可进入。

# 6. 白龙马开局

## 路线定位

白龙马是五人中最独特的“身份转换路线”：王子 → 犯罪者 → 囚徒 → 坐骑 → 龙魂觉醒者。

### LONGMA-01 西海龙宫

**地图**：西海龙宫、龙宫庭院、水域。

**玩法**：水域移动、龙族互动、宫廷关系。

### LONGMA-02 龙子

**剧情**：父子、继承压力、龙族秩序。

**玩法**：外交与仪式型探索；让玩家感受到白龙马不是普通怪物。

### LONGMA-03 逆鳞

**剧情**：犯错与审判。

**玩法**：短战斗 + 审判事件。

### LONGMA-04 鹰愁涧

**地图**：鹰愁涧、山崖、水潭。

**玩法**：长期被困环境；水陆转换。

### LONGMA-05 取经人

**剧情**：唐僧进入鹰愁涧范围，白龙与使命发生第一次联系。

**玩法**：跟踪、观察、救援型事件。

### LONGMA-06 白马

**剧情**：接受取经使命，成为坐骑。

**玩法变化**：角色控制从传统战斗角色切换为坐骑/探索功能。

**Milestone**：`BAI_LONGMA_RECRUITED`。

### LONGMA-07 沉默的旅伴

**剧情**：跟随唐僧与悟空踏上早期旅程。

**玩法**：移动辅助、逃脱、地形互动、隐藏资源发现。

### LONGMA-08 龙魂初醒

**剧情**：关键危机中恢复龙形战斗意志。

**玩法**：首次获得有限可战斗龙形；完整形态树留到共享主线成长。

**Milestone**：`LONGMA_COMBAT_AWAKENED`。

# 7. 五种开局的汇流矩阵

| 起始角色 | 玩家首先经历 | 第一个固定世界汇流 | 汇流后状态 |
|---|---|---|---|
| 孙悟空 | 花果山→天庭→五行山 | 唐僧/五行山 | 悟空进入唐僧队伍 |
| 唐僧 | 成长→取经→五行山 | 悟空/五行山 | 师徒二人开始西行 |
| 猪八戒 | 天蓬→猪刚鬣→高老庄 | 当前西游时间线的八戒加入点 | 八戒进入共同旅程 |
| 沙悟净 | 天庭→流沙河 | 当前西游时间线的沙僧加入点 | 沙僧进入共同旅程 |
| 白龙马 | 西海→鹰愁涧 | 当前西游时间线的白龙马加入点 | 成为坐骑并逐步觉醒 |

**注意**：这里的“当前西游时间线”是设计实现术语，不表示玩家可以把世界历史顺序改写成自己的开局顺序。

# 8. 起始角色与“立即回忆”的正式规则

## 规则 A：起始角色

新游戏选择谁，谁的历史路线立即进入可玩状态。

## 规则 B：正式相遇

如果当前共同旅程遇到/招募一个新角色，则：

```text
RecruitmentEvent
    ↓
route_status[character] = UNLOCKED
    ↓
available_memory_chapters += safe historical chapters
```

## 规则 C：不等待五人

例如：

```text
Tang Start
  ↓
meet Wukong
  ↓
Wukong personal route unlocked
  ↓
continue Tang + Wukong
  ↓
meet Longma
  ↓
Longma personal route unlocked
```

同理，从悟空、八戒、沙僧、白龙马开始，也必须在遇到其他角色时立即增加对应个人故事。

## 规则 D：回忆不推进世界时间

个人历史章节使用独立的 `historical_timeline`。

进入前保存：

- 当前世界 checkpoint
- 当前队伍
- 当前章节
- 当前任务状态
- 当前世界 milestone

退出后完整恢复。

## 规则 E：PARTY_FULL

`PARTY_FULL` 只意味着：

- 五人均已进入当前共同旅程
- 完整队伍编成可用
- 前后排轮换完全开放
- 五人联动技能开放
- 营地/团队关系层全面展开

它**绝不是个人故事解锁开关**。

# 9. 五种开局的真正 Replay Value

玩家第二周目选择另一个角色时，不应只是重新看一遍相同剧情。

应产生三个差异层：

### 视角差异

同一历史事件，镜头与可操作角色不同。

### 信息差异

第一次从唐僧看见悟空，会认为悟空是危险囚徒；第一次玩悟空再回头看五行山，则知道他已经经历过完整天宫悲剧。

### 玩法差异

不同开局前几小时使用完全不同的战斗/探索语言：

- 悟空：高速、多变、变身。
- 唐僧：判断、辅助、净化、外交。
- 八戒：重装、防御、仇恨、资源。
- 沙僧：控制、防守、耐久。
- 白龙马：移动、形态、地形、后期觉醒。

因此“五选一”不是菜单上的五个头像，而是**五种真正的第一章体验**。

# 10. 制作顺序

为了防止之后不断推倒重来，内容制作顺序固定为：

1. 已完成：悟空路线作为最高细节参考。
2. 当前：把唐僧、八戒、沙悟净、白龙马逐章提升到同一制作粒度。
3. 然后：定义每个招募事件之后的立即个人线解锁数据。
4. 然后：建立共同西行章节 Bible。
5. 最后才把章节内容转成 Godot 数据资源。

在共享主线完成前，不把任何一个角色的个人故事设计成 `PARTY_FULL` 的前置条件。
