## 非对称但固定的开局规则

### 孙悟空开局

悟空线本身已经覆盖世界历史最早阶段，因此到五行山后直接交给唐僧视角下已经发生的当前事件。玩家不会再次“从唐僧起源”重打一遍，而是从师徒建立后的共享章节继续。

### 唐僧开局

唐僧是最接近传统西游开局的路线。到五行山后触发悟空释放并立即把 `WUKONG_ROUTE` 标记为可回忆。

### 白龙马开局

白龙马的起源发生在共同取经时间线已启动之后。完成鹰愁涧转化后，直接进入已经存在的唐僧 + 悟空共同旅程；玩家看到的是“加入一支已经出发的队伍”。

### 猪八戒开局

八戒路线结束于高老庄招募。交接后直接进入高老庄后的共同章节，不重播花果山、五行山等早期事件。

### 沙悟净开局

沙悟净路线本身最靠近 `PARTY_FULL`。完成皈依后直接进入流沙河后的五人完整旅程。

## 进入后的历史回忆规则

任何已加入当前旅程的角色都可以拥有 `route_status = UNLOCKED` 的个人路线：

```text
遇见 / 招募角色
      ↓
写入 recruited_characters
      ↓
route_status[character] = UNLOCKED
      ↓
available_memory_chapters 增加该角色安全可回忆章节
      ↓
继续当前共享章节
```

个人路线的完成状态与共享世界进度分离：

- `route_status` 记录人物历史完成度。
- `current_global_timeline` 记录真实世界进度。
- `completed_shared_chapters` 记录当前西游旅程。
- 回忆完成不会推进 `current_global_timeline`。

## 设计验证表

以下五种新游戏都必须在最终实现中成立：

| 测试 | 必须成立 |
|---|---|
| 新游戏选择孙悟空 | 能完整玩悟空起源并自然进入共同西游 |
| 新游戏选择唐僧 | 能完整玩唐僧起源并自然遇见悟空 |
| 新游戏选择猪八戒 | 能完整玩天蓬→猪刚鬣→高老庄并进入共同旅程 |
| 新游戏选择沙悟净 | 能完整玩卷帘大将→流沙河并进入五人阶段 |
| 新游戏选择白龙马 | 能完整玩龙族→鹰愁涧→坐骑身份并进入共同旅程 |
| 已遇见新角色 | 立即出现该角色个人故事入口 |
| 未遇见角色 | 不提前开放其个人主线 |
| PARTY_FULL 前 | 已遇见角色的个人线照常可玩 |
| PARTY_FULL | 只新增完整队伍/团队内容，不突然批量解锁人物起源 |
| 回忆结束 | 精确返回进入前共享章节 |
