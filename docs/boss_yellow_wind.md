# 黄风妖王 Boss 设计

## 定位

黄风妖王是第一个完整教学型 Boss：让玩家在一场战斗里同时理解 **弱点、Break、BP、前后排、角色专属资源、Boss 阶段变化**。

## 三阶段

### 第一阶段 · 试探

- HP 100%–67%
- 弱点：火、风
- 护盾：6
- 基础攻击为主
- 玩家应学会观察弱点并积累 BP

### 第二阶段 · 黄风起

- HP 66%–34%
- 进入阶段时刷新护盾
- 释放「黄风起·飞沙走石」
- 风沙持续 2 回合
- 鼓励玩家在风沙前完成一次 Break

### 第三阶段 · 回风

- HP 33% 以下
- 再次刷新护盾
- 攻击 +8，速度 +4
- 开启「风刃回风」反击窗口
- 玩家应避免无脑连续攻击，寻找 Break 时机

## 教学目标

1. 先用弱点降低护盾。
2. Break 后用 BP 技能集中爆发。
3. 八戒承担前排风险，唐僧负责恢复。
4. 悟空利用 Break / 战意获得更高爆发。
5. 悟净与龙马提供控制和机动型解决方案。

## 情报奖励

玩家在首次战斗中可以逐步确认：

- 火弱点
- 风弱点
- 护盾数量
- 第二阶段风沙
- 第三阶段反击

这些情报应被后续悬赏妖王系统保存，形成“调查 → 准备 → 挑战”的闭环。
