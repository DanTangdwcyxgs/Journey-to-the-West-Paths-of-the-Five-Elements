# 悬赏妖王系统

## 定位

悬赏妖王是“重装机兵式自由探索思想”的西游化实现。

它们不是隐藏起来的纯收集品，也不是全部强制主线 Boss，而是玩家主动决定是否追猎的高价值世界目标。

## 核心循环

```text
获得传闻
  ↓
发现目标
  ↓
调查 / 侦察
  ↓
决定现在挑战还是暂缓
  ↓
准备队伍、站位、法宝、术式
  ↓
挑战
  ├─ 胜利 → 奖励 + 世界变化
  ├─ 撤退 → 保留已获得情报
  └─ 战败 → 可恢复并获得少量战斗情报
```

## 四个状态

`UNKNOWN`

玩家不知道目标存在。

`RUMORED`

听到传闻，但地点或弱点不完整。

`DISCOVERED`

已经确定目标位置，可以前往挑战。

`DEFEATED`

目标已击破，世界状态与奖励进入已完成状态。

## 强敌撤退规则

高危妖王允许主动撤退。

撤退不能产生“什么都没发生”的感觉。

应保存：

- 已发现地点
- 已见过的招式
- 部分弱点情报
- 危险等级
- 已触发的 Boss 开场演出

例如第一次挑战失败后：

```text
妖王资料更新：
- 火属性抗性：未知
- 风属性：可能有效
- 第二阶段：未知
- 危险等级：极高
```

## 与 Break/BP 的联动

悬赏妖王应优先设计成“研究型 Boss”。

玩家需要通过探索得知：

- 弱点
- 护盾数量
- 阶段变化
- 特殊状态
- 反击条件

正式战斗则要求玩家把这些信息转成队伍配置。

```text
情报 → 配置 → Break → BP 爆发 → 战利品
```

## 奖励层级

### 普通悬赏

铜钱 + 普通素材 + 图鉴进度。

### 高级悬赏

稀有灵材 + 特殊装备 + 营地升级资源。

### 传说悬赏

角色专属装备、特殊技能素材、隐藏路线或重要世界信息。

## 世界反馈

击败妖王必须让玩家感觉“世界真的发生了变化”。

允许的反馈包括：

- 村民重新出门
- 夜间封锁解除
- 商店增加特殊库存
- 新 NPC 出现
- 新支线开启
- 新地图路线开放
- 角色触发专属对话
- 《西游录》补全条目

## 与主线关系

悬赏妖王永远不能强迫玩家破坏主线节奏。

可以：

- 主线推进后再出现
- 主线中途提前发现
- 完成主线某个事件后升级
- 在旧地图开放新挑战

但绝不能通过悬赏系统改变西游世界的核心历史锚点。

## 回访规则

部分悬赏妖王必须依赖后期能力才能完成。

典型例子：

```text
第一次来到河谷
→ 发现封闭入口
→ 获取龙形能力
→ 回访
→ 发现隐藏路线
→ 发现 S 级妖王
```

因此世界地图需要支持 `revisit_conditions`。

## 设计底线

我们借鉴的是：

> 自主选择危险目标 + 准备后再挑战 + 强敌提供记忆点 + 奖励推动再次探索。

不照搬：

> 废土、战车、机械敌人、战车改造本身。
