# 《西游记》原著剧情参考库

本文件是本项目后续剧情梳理、章节重构与适配时使用的**原著参考入口**。它不是游戏脚本，也不直接驱动运行时。

## 来源与定位

- 参考仓库：`gazhikaba/xiyouji_txt`
- 参考仓库地址：<https://github.com/gazhikaba/xiyouji_txt>
- 当前固定参考版本：`419a54fbaf368af463dd863b8271ec7bb176b3b3`（2024-08-26）
- 上游说明：该仓库为《西游记》纯文本整理，并注明感谢 Chinese Text Project（ctext.org）。
- 辅助回目校对：Chinese Text Project《西游记》与 100 回本回目索引。

## 使用规则

1. 原著是**剧情事实与人物关系的第一参考层**；游戏剧情不是原著的机械复述。
2. 游戏可以做结构化改编、节奏压缩、分支化、战斗化和“五行路径”重构，但改动应能追溯到对应原著回目。
3. `data/narrative/*.json`、EventSequence 与战斗定义属于**游戏实现层**；本目录属于**创作参考层**，两者不直接混用。
4. 后续新增或重构章节时，优先在设计文档中标注 `xiyouji_chapter` / `xiyouji_chapters`，用于保留原著来源链。
5. 当游戏设定与原著发生冲突时，不默默改原著索引；应在剧情设计文档中明确记录“改编点”。

## 当前项目的直接关联区段

本项目当前的第一 Vertical Slice 主要落在原著前 22 回的核心路径：

- **悟空起源**：1–7 回，重点是花果山、求道、天宫、五行山。
- **唐僧前史与取经缘起**：8–14 回，重点是金蝉转世、玄奘身世、双叉岭与收悟空。
- **白龙马**：15 回，鹰愁涧。
- **黑风山前段**：16–17 回，可作为唐僧与悟空早期共同旅程的重要参考。
- **八戒**：18–19 回，高老庄、云栈洞、浮屠山。
- **黄风岭**：20–21 回，是三藏西行早期妖患与悟空护师的重要节点。
- **悟净**：22 回，流沙河与木叉奉法收悟净。

这一区段与当前 `Origin Route → Shared Journey` 的设计高度重合，因此后续剧情梳理应优先以这些回目校正角色出场顺序、地名、战斗节点、人物关系与世界时间线。

## 改编记录建议

后续每次重要剧情改动建议记录：

```text
xiyouji_chapters: [15]
adaptation: "将鹰愁涧拆为选择 → 战斗 → 招募 → 后记四段 EventSequence"
reason: "适配 RPG 战斗循环并保留原著事件顺序"
```

这样可以让后续剧情设计同时回答两个问题：**“原著发生了什么？”** 和 **“我们的游戏为什么这样改？”**。
