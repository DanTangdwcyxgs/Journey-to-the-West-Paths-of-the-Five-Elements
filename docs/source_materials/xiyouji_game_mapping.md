这份文档用于后续剧情设计，不是运行时配置。

## 当前应优先校正的原著事实

### 角色出场顺序

经典主线的核心顺序是：玄奘取经缘起 → 悟空 → 龙马 → 八戒 → 悟净。游戏的 Origin Route 与 Shared Journey 必须保持这个大方向，不应为了玩法便利提前让后续角色稳定进入队伍。

### 鹰愁涧

鹰愁涧对应龙马真正进入取经队伍的关键节点。后续战斗、招募、记忆章节都可以继续扩写，但不应改变其“玄奘一行遭遇白龙、白龙最终成为白龙马”的主线位置。

### 黑风山

16–17回属于早期师徒共同冒险的重要连续段落。当前 Shared 04 可以作为一个压缩后的游戏章节，但未来应保留“观音院 → 袈裟失窃 → 黑风山追索 → 熊罴怪”这一因果链。

### 高老庄与八戒

18–19回不是单纯的一场招募战，而是“高老庄妖患 → 云栈洞交锋 → 八戒被悟空降伏 → 浮屠山心经”的连续过程。未来 Shared 05 的 EventSequence 可以继续拆成更多对白、选择与战斗节点。

### 黄风岭

20–21回承担早期取经路上“唐僧被妖怪威胁、悟空解决大难”的升级作用。这里适合承担队伍从‘刚刚组成’向‘真正开始护送取经’过渡的剧情功能。

### 流沙河

22回是悟净加入的核心节点。游戏化时可以把“多次交锋 → 木叉出现 → 悟净受度”拆成选择、战斗、招募和战后对白，而不应只保留一个瞬间性的 recruit 标记。

## 后续剧情梳理要求

后续新增章节优先回答四个问题：

1. 对应原著哪一回或哪几回？
2. 原著中的因果链是什么？
3. 为了 RPG 节奏做了哪些删减、合并或前后调整？
4. 哪些内容属于本项目新增的“五行 / 路线 / 记忆 / 分支”原创层？
