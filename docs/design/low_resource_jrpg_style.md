# 《西游：五行之路》低资源 JRPG 制作方向

## 核心目标

第一版不是追求 HD-2D 的最终美术，而是先做出一款真正可以从头玩到尾的西游 JRPG：选主角、个人序章、地图移动、事件、队伍、回合战斗、招募、装备/成长、存档和共享主线全部可运行。

整体体验参考《八方旅人》的“多主角入口 + 小型场景 + 强角色故事 + 回合制战斗”结构；资源生产采用《重装机兵/早期 2D RPG》式的节省思路：小尺寸角色、有限色盘、瓦片复用、少量关键帧、程序化特效、程序化音效。

## 第一阶段视觉规则

- 场景：以 16×16 / 32×32 瓦片为最小复用单位，地图由地面、道路、山石、树木、建筑等少量基础块拼装。
- 角色：先使用低资源程序角色和占位立绘，统一角色骨架/朝向/动画槽；后期只替换纹理，不改剧情和战斗逻辑。
- 场景层：远景、中景、可行走区域、事件标记四层即可，不追求复杂 3D。
- 战斗：角色站位 + 少量攻击帧 + 屏幕震动/闪白/数字飘字解决打击反馈。
- UI：保留 JRPG 信息密度，但减少“网页表单感”，逐步改成地图/人物/对话框驱动。

## 音效规则

初版用 AudioStreamGenerator 程序合成基础反馈：确认、取消、脚步、攻击、命中、破防、胜利、失败。剧情 BGM 先预留统一接口，后续有音乐资源再接入，不让音频资源卡住玩法开发。

## 开发优先级

1. 五位主角选择与个人序章完整可玩。
2. 个人序章汇合到固定西游主线。
3. 世界地图与地点切换。
4. 回合制战斗与招募/成长。
5. 统一的低资源视觉表现。
6. 基础音效与关键节点音乐接口。
7. 最后才替换高质量角色立绘、背景、动画和演出。

## 最重要的工程原则

**玩法数据与美术资源彻底解耦。** `EventSequence`、角色 ID、敌人 ID、战斗系统、存档系统不直接依赖具体 PNG/SVG。将来拿到更好的像素素材、八方旅人式 HD-2D 资源或外部美术包时，只替换视觉资源层即可。
