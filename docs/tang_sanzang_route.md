# 唐僧主线：The Pilgrim

## 核心主题

**信仰 vs 现实**。

唐僧不是“开局自带一堆经书的治疗师”，而是从一个相信教义、相信善恶秩序的人，逐渐进入一个善恶边界混乱、妖魔横行、神佛也并非简单善恶二分的世界。

## 唐僧线玩法

唐僧最重要的“武器”是判断与准备。

- 经文/符箓
- 净化
- 护盾
- 祝福
- 说服/外交
- 对妖魔伪装的识别
- 风险管理

唐僧战斗力弱，但不是无聊。他必须让玩家觉得：

> 没有唐僧，悟空只是一个强大的野猴王；没有悟空，唐僧也走不到西天。

## 五行山交汇

TANG-07 与 WUK-15 共用同一个 World Event：`FIVE_ELEMENTS_MOUNTAIN`。

但两条路线的镜头、对白、交互重点不同：

- 悟空线：囚徒视角
- 唐僧线：救赎者/师父视角

两个玩家最终看到的是同一件事，却会产生完全不同的情绪记忆。

## 入队变化

唐僧并不是被“招募”，因为他就是玩家可选的起始主人公之一。

当悟空加入后，唐僧的角色定义从 `solo_pilgrim` 切换为 `party_leader`，获得：

- 队伍指令能力
- 紧箍咒
- 集中防护
- 圣言类技能

同时正式进入共享旅程。
