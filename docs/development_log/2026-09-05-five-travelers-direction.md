# 2026-09-05 — 确立“五方旅人”低资源 JRPG 方向

## 决策

本日正式确定《西游：五行之路》的长期产品方向：

- **游戏框架与游戏性参考《八方旅人》**：多主角开局、个人故事、旅途中相遇/招募、区域探索、回合制战斗、角色职业与能力、个人路线最终汇入共同世界线。
- **项目核心结构为“五方旅人”**：唐三藏、孙悟空、猪八戒、沙悟净、白龙马五位主角分别代表五个西游视角。
- **剧情依据《西游记》原著真实小说主线**：游戏化增加探索、战斗、支线和演出，但不把核心西游历史改成另一套原创世界观。
- **初版画面采用低资源复古像素方案**：参考古老 JRPG（尤其《重装机兵》时代）的 TileMap、小型 sprite、少量动画帧、共享场景组件与程序化效果。
- **高质量美术延后**：等核心玩法和内容完成后，再逐步替换为更高品质像素或 HD-2D 素材。
- **音效同样低资源优先**：先用短音效/程序化声音解决操作反馈，不让大体积音频资源阻塞开发。

## 为什么这么做

当前项目已经有较完整的剧情事件协议、人物路线、共享西游时间线和战斗桥接，但之前的 Web Demo 暴露出一个明显问题：虽然剧情逻辑已经能跑，玩家看到的体验仍然偏向文字冒险。

因此下一阶段不再继续单纯增加剧情数据，而要把已经存在的剧情/战斗/路线系统包装成真正的 RPG 游玩循环。

## 第一条 Vertical Slice

优先做到：

`选人 → 个人序章 → 可移动地图 → NPC/事件 → 第一次战斗 → 战斗奖励 → 成长/装备 → 招募/关键事件 → 汇入共同西游主线 → 存档`

这个闭环完成后，项目才算真正进入 JRPG 原型阶段。

## 资产策略

所有低资源资产都必须尽量与逻辑解耦：

- 角色 sprite 可替换。
- 地图 TileSet 可替换。
- 战斗背景可替换。
- UI 主题可替换。
- 音效可替换。
- 程序特效可继续使用。

未来升级画面时，不应该推倒重做剧情、地图、战斗和存档代码。

## 后续开发准则

遇到新功能时，优先判断它是否增强：

> “西游版八方旅人 / 五方旅人”的可玩体验。

如果只是增加更多文字、说明或展示，却没有增强 RPG 探索、战斗、成长、选择和反馈，就不应排在核心玩法之前。
