# 五种开局完整设计：Five Starting Routes

## 1. 设计目标

五个角色都必须是**真正成立的主角开局**，而不是“同一条游戏从不同章节开始”。

玩家在新游戏中可以自由选择：

- 唐僧
- 孙悟空
- 猪八戒
- 沙悟净
- 白龙马

每个开局都必须提供：

1. 独立的起源故事
2. 独立的前期地图与玩法节奏
3. 独立的角色成长曲线
4. 一个明确的历史终点/入队节点
5. 与固定世界时间线的第一次汇流
6. 汇流后继续推进当前西游主线
7. 每遇到并正式纳入当前队伍旅程的角色，**立即解锁该角色截至当前时间点的个人历史/主线回忆**

这里的“立即解锁”不是必须立刻游玩，而是玩家从这一刻起拥有进入该角色个人故事的资格。

## 2. 核心规则：五个入口，只有一条世界历史

```text
                  固定世界历史
                       │
       ┌───────────────┼───────────────┐
       │               │               │
   Wukong Start    Tang Start      Bajie Start
       │               │               │
       └──────┬────────┴────────┬──────┘
              │                 │
          Longma Start      Wujing Start
              │                 │
              └───────┬─────────┘
                      ↓
                 共同西游世界
```

**玩家游玩顺序可以不同，但世界事件顺序不可改变。**

例如：

- 从八戒开始，不代表世界先发生高老庄。
- 从白龙马开始，不代表唐僧尚未出发的世界会倒放。
- 从悟空开始，也不意味着唐僧线被删除。

玩家是在游玩某个人的历史，然后通过时间锚点回到共同世界。

## 3. 五个开局的共同生命周期

```text
选择角色
  ↓
该角色完整起源线
  ↓
角色达到历史汇流点
  ↓
进入/连接当前世界时间线
  ↓
遇见下一名角色
  ↓
立即解锁下一名角色个人故事
  ↓
继续共同旅程
  ↓
再遇见下一名角色
  ↓
再次增加可回忆角色
  ↓
PARTY_FULL
  ↓
完整西游旅程
```

注意：`PARTY_FULL` 只代表五人完整汇流，不负责开放前四名角色的个人故事。

# 4. 开局 A：孙悟空

## 玩家第一感受

> “我就是孙悟空。”

这是五个开局中最强调动作、战斗、成长与自由感的入口。

## 4.1 起源阶段

```text
石猴出世
→ 水帘洞
→ 寻仙问道
→ 菩提门下
→ 初得神通
→ 龙宫取宝
→ 地府改命
→ 天庭任职
→ 齐天大圣
→ 蟠桃/天宫冲突
→ 二郎神
→ 炼丹炉
→ 大闹天宫
→ 五行山
```

对应现有 WUK-01 ~ WUK-15。

## 4.2 玩家玩法成长

### 第一阶段：野猴

- 基础近战
- 跳跃/攀爬探索
- 简单棍击
- 野外资源

### 第二阶段：学艺

- 棍法连段
- 身法
- 七十二变雏形
- 火眼金睛

### 第三阶段：大圣

- 多段棍击
- 变身
- 分身
- 高爆发
- 更强破盾能力

### 第四阶段：天宫

敌人等级、属性、技能复杂度明显上升。

## 4.3 汇流点

`WUK-15 五行山`

悟空不是“结束游戏”，而是完成第一个主角阶段。

随后：

```text
五行山
→ 唐僧到来
→ 紧箍/师徒冲突
→ Wukong 成为当前队伍成员
→ Tang 进入玩家当前共同旅程
```

若玩家此前只玩悟空，则此时获得唐僧的个人历史入口：

`TANG_ROUTE_UNLOCKED`

## 4.4 悟空开局之后的个人故事解锁节奏

```text
Wukong Start
  ↓
遇到唐僧
  ↓
解锁唐僧个人线
  ↓
继续师徒西行
  ↓
遇到白龙马
  ↓
解锁白龙马个人线
  ↓
到高老庄遇八戒
  ↓
解锁八戒个人线
  ↓
流沙河遇沙僧
  ↓
解锁沙僧个人线
```

因此悟空开局最终仍然可以看到其他四人的完整人生，只是解锁顺序严格跟随实际相遇。

# 5. 开局 B：唐僧

## 玩家第一感受

> “我没有神通，也没有强大战力，但我要走完这条路。”

这是最典型的“西游旅程入口”。

## 5.1 起源阶段

```text
金蝉转世
→ 江流儿/少年
→ 出家
→ 受戒
→ 佛法学习
→ 取经使命
→ 观音指引
→ 离开长安
→ 五行山
```

对应现有 TANG-01 ~ TANG-07。

## 5.2 前期玩法

唐僧必须在没有悟空之前仍然可玩：

- 探索
- NPC 交流
- 判断真假
- 经文/符箓
- 基础法术
- 防御与治疗
- 资源管理

战斗不是靠输出，而是靠生存与准备。

## 5.3 第一次汇流

`FIVE_ELEMENTS_MOUNTAIN`

唐僧视角：

- 看到山下囚徒
- 听见悟空请求
- 与土地/神灵/当地人交流
- 形成“是否相信悟空”的判断
- 最终揭开孙悟空的历史

悟空加入后：

`WUKONG_ROUTE_UNLOCKED`

这就是八方旅人式的第一层角色故事入口。

## 5.4 唐僧之后

```text
唐僧
→ 悟空加入
→ 悟空个人故事可回忆
→ 师徒继续前进
→ 白龙马
→ 白龙马个人故事可回忆
→ 八戒
→ 八戒个人故事可回忆
→ 沙僧
→ 沙僧个人故事可回忆
```

唐僧开局因此是最符合经典西游“取经人视角”的版本。

---

# 6. 开局 C：猪八戒

## 玩家第一感受

> “我曾经是天蓬元帅，但现在我只是一个想活得舒服一点的猪妖。”

这一开局必须避免“开局直接高老庄”。玩家先拥有完整的身份落差。

## 6.1 起源阶段

```text
天蓬元帅
→ 天河旧日
→ 天庭生活
→ 与秩序冲突
→ 获罪
→ 被贬
→ 错投猪胎
→ 猪刚鬣
→ 云栈洞
→ 高老庄
```

对应 BAJIE-01 ~ BAJIE-06。

## 6.2 玩法成长

### 天蓬阶段

- 长兵器
- 高额防御
- 军阵技能
- 天庭环境

### 猪刚鬣阶段

玩法发生转变：

- 饥饿/食物资源
- 厚血
- 强力防御
- 嘲讽
- 受伤强化
- 钉耙蓄力

角色系统本身体现“从天将到猪妖”的反差。

## 6.3 高老庄汇流

高老庄不是简单 Boss 房。

完整结构：

```text
高老庄探索
→ 高家关系
→ 夜间调查
→ 八戒隐藏身份
→ 悟空进入事件
→ 连续误会
→ 八戒战斗
→ 唐僧介入
→ 八戒认清取经道路
→ 招募
```

## 6.4 最特殊的开局连接

因为八戒是后加入角色，因此玩家在正式接触到唐僧/悟空之前，已经经历了八戒自己的完整历史。

当高老庄完成并进入共同世界时，玩家第一次从八戒视角见到唐僧与悟空。

如果继续游戏并随后完成其他角色汇流：

- 遇悟空 → 悟空个人线解锁
- 遇唐僧 → 唐僧个人线解锁
- 遇白龙马 → 白龙马个人线解锁
- 遇沙僧 → 沙僧个人线解锁

已经完成的八戒历史不会重复播放，而会以“已完成/可重访”的方式记录。

# 7. 开局 D：沙悟净

## 玩家第一感受

> “我犯过错。我在流沙河里活了很久。我只想知道自己还能不能被原谅。”

沙僧是五个开局中最偏“沉静、生存、救赎”的入口。

## 7.1 起源阶段

```text
卷帘大将
→ 天庭生活
→ 失手/获罪
→ 被贬流沙河
→ 河中孤囚
→ 与路人/妖物长期冲突
→ 观音渡厄
→ 取经人到来
→ 加入队伍
```

对应 WUJING-01 ~ WUJING-08。

## 7.2 玩法成长

前期强调：

- 水域移动
- 控制
- 防御
- 消耗战
- 水冰法术
- 反击

中期逐步获得：

- 群体冻结
- 水幕
- 减速
- 领域控制

沙僧不追求悟空式爆发，而是不断让战场变得对自己有利。

## 7.3 流沙河汇流

这是沙僧第一次真正拥有：

`Current Journey Party Membership`

与此同时：

`SHA_WUJING_ROUTE_COMPLETE`

并将之前已经在队伍里的角色个人故事保持为可访问状态。

如果这是从沙僧开始的首次游戏，则之后随着剧情前进逐步解锁：

```text
遇到唐僧
→ 唐僧线解锁

确认/接触悟空
→ 悟空线解锁

接触白龙马
→ 白龙马线解锁

接触八戒
→ 八戒线解锁
```

具体触发点服从真实西游事件顺序，而不是为了“平均分配”而人为调整。

# 8. 开局 E：白龙马

## 玩家第一感受

> “我不是一个人类主角。我的故事从龙宫开始。”

这是最需要特殊处理的开局。

白龙马前期不应该像普通 RPG 五号队员。

## 8.1 起源阶段

```text
西海龙宫
→ 龙子身份
→ 王族关系
→ 犯错
→ 审判/死刑威胁
→ 鹰愁涧
→ 困守
→ 唐僧经过
→ 龙马化
```

对应 LONGMA-01 ~ LONGMA-06。

## 8.2 独特玩法

### 第一阶段：龙

玩家拥有：

- 水域移动
- 飞行/跳跃
- 爪/龙息
- 高机动探索

### 第二阶段：鹰愁涧

重点是生存与逃脱。

### 第三阶段：白马

这里故意把能力压缩：

- 移动
- 驮载
- 逃脱
- 提供机动
- 非战斗交互

玩家会产生：

> “我的主角怎么变成坐骑了？”

这是设计目标，不是缺陷。

## 8.3 第二层觉醒

加入取经队伍一段时间以后，触发：

`LONGMA_COMBAT_AWAKENED`

第一次恢复真正的战斗形态。

随后逐步开放：

- 鹰
- 虎
- 龙
- 马

多形态战斗系统。

## 8.4 白龙马开局的历史解锁

白龙马开始游戏后，先完成自己的过去。

等遇见唐僧并成为坐骑/队伍成员后：

`TANG_ROUTE_UNLOCKED`

之后随着真实事件：

```text
接触悟空 → WUKONG_ROUTE_UNLOCKED
接触八戒 → BAJIE_ROUTE_UNLOCKED
接触沙僧 → WUJING_ROUTE_UNLOCKED
```

而不是因为“白龙马必须等五人集齐”。

# 9. 五种开局的玩家体验差异

| 开局 | 前期核心 | 第一汇流 | 开局节奏 | 最大特色 |
|---|---|---|---|---|
| 悟空 | 成长/战斗 | 五行山 | 最长 | 从石猴到大圣 |
| 唐僧 | 探索/判断/生存 | 五行山 | 最接近经典西游 | 最正统取经视角 |
| 八戒 | 防御/资源/生存 | 高老庄 | 喜剧+苦涩 | 天蓬到猪妖 |
| 沙僧 | 控制/耐久 | 流沙河 | 沉静 | 孤囚到护法 |
| 白龙马 | 形态/移动 | 鹰愁涧 | 最特殊 | 龙→马→龙战士 |

## 10. 开局公平性原则

五个开局不能做成简单的“一个有十章，另一个只有三章”。

公平性不是章节数量完全相同，而是：

```text
叙事完整度 ≈ 玩法完整度 ≈ 角色成长完整度
```

因此：

- 悟空前期最长，但战斗内容最多。
- 唐僧前期战斗较少，但探索、判断和剧情密度高。
- 八戒前期地图较集中，但角色变化最剧烈。
- 沙僧前期地图较孤立，但生存与控制体验完整。
- 白龙马前期玩法特殊，因此必须靠形态转换与探索机制补足体验。

## 11. 存档必须记录的开局信息

```text
starting_character
starting_route_status
current_global_timeline
current_shared_chapter
recruited_characters
route_status_by_character
completed_chapters_by_character
available_memory_chapters
played_memory_chapters
party_full
```

## 12. 最终目标

无论玩家选择谁开局，完整游戏最终都应该回答同一个问题：

> 五个原本完全不同的人，为什么最终会一起走上西天取经的路？

但每个玩家看到答案的第一章都不同。

```text
悟空开局：我曾经无所畏惧。
唐僧开局：我必须完成使命。
八戒开局：我曾经逃避责任。
沙僧开局：我希望得到救赎。
白龙马开局：我必须找到自己的身份。

最终：
他们都成为了取经队伍。
```
