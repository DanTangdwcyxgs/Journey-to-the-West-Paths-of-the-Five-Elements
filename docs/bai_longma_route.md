# 白龙马主线：The Dragon's Oath

## 核心主题

**身份 vs 使命**。

白龙马必须明显区别于其他四人：他不是“第五名普通队员”，而是从龙族王子一路变成取经坐骑，再逐步觉醒为真正的战斗角色。

## 特殊设计：先是“马”，后是“龙”

白龙马在队伍中加入时不立即开放完整技能树。

前期：

`Party Mount / Exploration Utility`

后期：

`Playable Combatant / Transformation System`

这是整个角色设计的反差核心。

## 玩法

- 马形态：移动、拉条、逃脱、队伍机动
- 鹰形态：高速、闪避、先手
- 虎形态：单体破防、强力打击
- 龙形态：雷、水、范围攻击

形态切换应属于战斗决策，而不只是视觉变化。

## 入队

白龙马在鹰愁涧事件结束后正式进入队伍的“移动/坐骑”层，但 `BAI_LONGMA_COMBAT_AWAKENED` 要延迟到后续共享章节。

这样玩家会经历一次完整的认知变化：

> “它只是我们的马。”
>
> → “等等，它是龙。”
>
> → “它真的可以战斗。”

## 叙事要求

白龙马需要拥有较多不依靠对白的角色表达：

- 对龙族符号的反应
- 对河流/水域的特殊互动
- 对天庭旧闻的反应
- 与唐僧的信任
- 与悟空的相互试探

## 入队后的个人线

白龙马的回忆章节主要回答三个问题：

1. 为什么龙族身份让他痛苦？
2. 为什么他愿意接受坐骑身份？
3. 为什么他最终要以自己的意志成为战斗者，而不是只做别人脚下的马？
