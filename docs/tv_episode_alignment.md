# 1986 TV Series Alignment

The 1986 CCTV *Journey to the West* adaptation is the primary external pacing reference for the shared pilgrimage. CCTV lists 25 episodes, beginning with `猴王初问世`, `官封弼马温`, `大圣闹天宫`, `困囚五行山`, then moving into `猴王保唐僧`, `祸起观音院`, `计收猪八戒`, `坎途逢三难`, and the later pilgrimage arcs. See: https://tv.cctv.com/2013/03/13/VIDA1363160804431165.shtml

## Adaptation Rule

The game should preserve the recognizable order and dramatic meaning of the major television events while expanding them into interactive JRPG chapters.

Do not copy television dialogue or shot-for-shot staging. Recreate the event as playable content with original implementation and writing.

## Important Recruitment Alignment

The game treats the following as non-negotiable primary anchors:

1. Wukong's mythic prelude before Tang's pilgrimage.
2. Wukong's imprisonment beneath Five Elements Mountain.
3. Tang's arrival and release of Wukong.
4. White Dragon / Bai Longma becoming the pilgrimage mount.
5. Gaojiazhuang and Zhu Bajie's recruitment.
6. Flowing Sands River and Sha Wujing's recruitment.
7. Full party convergence.

The early recruitment sequence is consistent with the broad 1986 TV progression, while exact in-game chapter count will be expanded for JRPG pacing.

## Translation from Television to JRPG

A television episode is not required to equal one game chapter.

A single TV episode may become:

`town scene → exploration → NPC investigation → ordinary battles → character scene → dungeon → boss → aftermath`

Likewise, several short television scenes may be combined into one game chapter when that produces a better playable rhythm.

## Canonical Event Ownership

Every TV anchor receives one authoritative game implementation.

Other character routes may reference the event through:
- memory;
- reaction dialogue;
- optional perspective scene;
- aftermath;
- relationship scene.

They must not create a second contradictory version.

## Shared Journey Target

Once the party is complete, the default main route follows the recognizable pilgrimage sequence represented by the television adaptation. Original connective material may expand the journey, but the major anchors above remain visible to players familiar with the series.
