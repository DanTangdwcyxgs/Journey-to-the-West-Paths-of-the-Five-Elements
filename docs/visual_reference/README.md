# Battle UI 视觉母版

本目录保存 2026-09-05 用户提供的战斗 UI 参考图，以及对应的长期视觉规范。

## 参考图

`battle_ui_reference.webp` 是用户在本次工作会话中提供的参考画面压缩版，用于后续模型接手时直接理解目标构图与 UI 语言。

原始聊天参考图：1024×559 PNG。
仓库保存版本：384×210 WebP，主要用于长期项目参考与轻量版本控制。

## 视觉标准

- 硬朗 2D 像素 JRPG HUD，不使用圆角 Web 卡片式 UI。
- 面板采用明确的 45° 切角、双层描边、装甲片结构。
- 主体底色为深蓝黑；青绿色用于正常信息、选中态和操作提示；金色/橙色用于敌方目标、战斗重点与警示；红色用于危险或受击状态。
- 边框需要有像素级细线、短横点阵、铆钉/固定点等结构装饰，但不能喧宾夺主。
- 顶部保留行动顺序条 / Action Queue，角色以小型头像格或标记表现行动次序。
- 右上区域是目标信息核心区：TARGET、HP、WEAK、SHIELD；弱点必须成为明确的战斗信息，而不是普通文字。
- 左下显示当前角色的 Frame Status，包括 HP、资源条/MP/BP、热量或其他专属战斗资源。
- 中下区域是 COMMAND / ACT，技能与行动选择必须围绕中央战场组织。
- 右下区域是 TEAM / PARTY 状态，不应变成普通表格。
- 字体应优先采用真正的像素等宽字体；当前仓库若没有合适中文像素字体，可先使用紧凑统一字体，但不能改变整体排版标准。
- 场景、角色、敌人和地图也必须服从同一套低分辨率像素语言，禁止回退成“圆头 + 方身体”的程序几何人物。

## 实现原则

视觉规范是全项目长期基线，不只适用于战斗页面。不同页面允许有不同信息布局，但面板几何、描边语言、颜色层级、像素密度和状态条风格必须统一。

后续模型接手时，先查看本目录中的参考图，再查看 `ui/pixel_frame.gd`、`ui/pixel_ui.gd`、`ui/pixel_hud.gd`，确认新增 UI 不偏离该标准。
