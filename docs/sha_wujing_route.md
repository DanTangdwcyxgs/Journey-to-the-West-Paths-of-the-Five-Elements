# 沙悟净主线：The Exile

## 核心主题

**罪责 vs 救赎**。

沙悟净是五人中最安静的一条个人线。它不靠夸张的反转，而靠漫长的孤独、重复的惩罚和最终重新获得人的连接建立角色重量。

## 沙僧玩法

- 水系攻击
- 减速、冻结、潮湿
- 防御与承伤
- 稳定的弱点削减
- 持久战优势
- 河流/水面地图互动

## 叙事要求

沙悟净不能为了突出沉默而变成没有对白的人。玩家需要通过少量但关键的台词感受到他的判断力和经历。

他的第一条真正长线目标不是“打败敌人”，而是“结束永无止境的流放”。

## 入队

`FLOWING_SANDS_RIVER_REACHED` 触发后，完整运行 WUJING-07。

击败并理解沙悟净之后进入 WUJING-08。该章节结束时设置 `SHA_WUJING_RECRUITED` 与 `PARTY_FOURTH_MEMBER`。

## 入队之后

共享旅程中，沙悟净主要承担：

- 稳定队伍
- 判断局势
- 对悟空和八戒之间的争执提供第三视角
- 在关键时刻承担责任

个人回忆章节用于展示他与天庭旧事的关系。
