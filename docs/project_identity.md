# 项目名称与对外身份

## 正式中文名（当前工作名）

# 《西游：五行之路》

## English Working Title

**Journey to the West: Five Elements Road**

## 项目类型

像素 HD-2D / 2.5D 回合制叙事 JRPG

## 核心卖点

**五个角色、五条人生起点、一条固定西游历史。**

## 玩家体验定位

玩家选择一个角色作为第一视角，体验其个人历史；故事抵达经典西游节点后汇入共同时间线。随着取经队伍逐渐形成，个人故事继续以 Memory / Character Perspective 方式展开，最终五人共同完成西天取经。

## 对外介绍优先级

所有公开页面都优先让第一次看到项目的人在 30 秒内理解：

1. 这是西游题材的 JRPG，而不是普通原创 RPG。
2. 五人都可以作为起始角色。
3. 玩家选择的是视角，不是改变历史。
4. 世界时间线固定，最终五条路线汇流。
5. 战斗采用 Weakness / Shield / Break / BP / Formation 等现代 JRPG 机制。
6. 游戏重点是“人物故事 + 旅途 + 队伍关系 + 战斗”，而不是只有刷怪。

## 命名原则

未来公开介绍应优先使用：

**《西游：五行之路》**

不要再把 `Black Myth: Wukong — JRPG Edition` 当作项目品牌主标题；它只能作为历史工作名称/旧仓库标题背景信息，避免让外部投资人误认为项目属于《黑神话：悟空》或与其存在官方关系。
